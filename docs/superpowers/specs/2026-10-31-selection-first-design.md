# 點選式餐點推薦

使用者已明確指定：解決選擇困難，規劃下一餐不要求輸入菜名、份數或偏好，日常決策全部點選；並已授權由代理選擇可落地方式直接執行。

採用預設推薦入口，而非必填問卷或大量菜單：一鍵幫我決定；預設 1 人份、30 分鐘、晚餐；份數與時間可直接選，餐別／優先條件／風味可收合。固定條件沿用帳號資料。互斥條件使用單選語意。原生與 Web 共用 allowlist 選項及純函式請求組合器，不改資料表、不降低後端過敏／食譜驗證。

選項式條件仍由 AI 執行，需驗證回傳份數／時間是否符合；尚未建立完整限制驗證前不能宣稱所有偏好皆為硬保證。具體指定菜名的後端能力保留；主流程無自由文字欄。其他輸入密集流程的缺口與產品排序記於 reviews/2026-10-31-product-gap-audit.md。
